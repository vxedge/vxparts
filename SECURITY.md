# Security policy

Do not open a public issue for a security report.

Report vulnerabilities in vxparts privately through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**
(https://github.com/vxedge/vxparts/security/advisories/new).

In scope: the build recipes, part descriptors and publish scripts in this repository.
Supply-chain issues are in scope too, for example an unpinned base image digest or a licensed
artifact that was committed or published by mistake.

Supported versions, response targets, and scope notes are in the vxedge organization
security policy: https://github.com/vxedge/.github/blob/main/SECURITY.md
