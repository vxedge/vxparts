# vxparts

Part of the **vxedge** research platform.

**Purpose:** the unified loadable registry — zone VM/RTOS bundles, central-compute
container images, gateway/TCU images, and agent binaries — all published to
`ghcr.io/vxedge/parts/...` via OCI/ORAS, classified by class/subtype/layer. Supersedes
the former `vxzones`/`vxcompute` split (see `TASKS.md` Track P).

See [vxedge/docs](https://github.com/vxedge/docs) for research plan and architecture.
